# 🎬 Netflix Content Intelligence Dashboard

An interactive **Power BI dashboard** designed to analyze Netflix content, release trends, ratings, content types, and global distribution.

## 📊 Project Overview

The Netflix Content Intelligence Dashboard provides an interactive view of Netflix's content library.

The dashboard helps analyze the distribution of **Movies and TV Shows**, content additions over time, release-year trends, ratings, and overall content growth.

## ✨ Dashboard Features

- 🎬 Total Netflix Titles
- 🎥 Total Movies
- 📺 Total TV Shows
- 📈 Movie Percentage
- 🌍 Unique Countries
- 👨‍🎬 Unique Directors
- 📅 Netflix Content Addition Trends
- 🎭 Movies vs TV Shows Distribution
- 📊 Content Distribution by Release Year
- ⭐ Content Distribution by Rating

## 📌 Key Dashboard Metrics

The dashboard provides important KPIs such as:

- **Total Titles**
- **Total Movies**
- **Total TV Shows**
- **Movie Percentage**
- **Unique Countries**
- **Unique Directors**

These KPIs provide a quick overview of the Netflix content library.

## 📈 Visualizations

### Netflix Content Addition Trend

Shows how Netflix content additions changed over the years.

### Content Mix: Movies vs TV Shows

Displays the distribution between movies and TV shows.

### Content Distribution by Release Year

Shows the number of Netflix titles released across different years.

### Content by Rating

Displays the distribution of Netflix content across ratings such as:

- TV-MA
- TV-14
- TV-PG
- And other ratings

## 📂 Dataset

The dashboard is based on Netflix titles data containing information such as:

- Title
- Type
- Director
- Cast
- Country
- Date Added
- Release Year
- Rating
- Duration
- Listed In
- Description

## 🔄 Data Preparation

The dataset was prepared using **Power Query**.

The data preparation process included:

- Removing unnecessary columns
- Handling missing values
- Cleaning text data
- Changing data types
- Transforming columns
- Preparing data for visualization

## 🧩 Data Modeling

The cleaned dataset was loaded into Power BI and prepared for analysis.

DAX measures and calculated fields were used to create the dashboard KPIs and visualizations.
